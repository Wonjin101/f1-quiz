# 🏎️ F1(포뮬러 1) 상식 콘솔 퀴즈 게임

## 1. 프로젝트 개요
Python의 객체 지향 프로그래밍(클래스)과 표준 라이브러리(json, os)를 활용하여 제작한 터미널 기반의 F1 상식 4지선다 퀴즈 프로그램입니다. 사용자가 퀴즈를 풀고, 새로운 퀴즈를 등록하고, 최고 점수를 기록할 수 있으며 모든 데이터는 state.json 파일에 영구 저장(데이터 영속성)됩니다.

## 2. 퀴즈 주제와 선정 이유
- **주제:** F1 (Formula 1, 포뮬러 원 모터스포츠)
- **선정 이유:** 빠른 속도감 뒤에 숨겨진 F1의 정교한 레이스 규정과 전략(DRS, 타이어 컴파운드, 서킷 특징, 포인트 제도 등)을 4지선다 퀴즈를 통해 쉽고 재미있게 소개하고 싶어 선정했습니다.

## 3. 실행 방법
- **요구 환경:** Python 3.10 이상 (외부 라이브러리 불필요)
- **실행 명령어:** 프로젝트 루트 폴더에서 `python3 main.py` 입력

## 4. 기능 목록
1. **퀴즈 풀기:** 등록된 모든 F1 퀴즈를 순서대로 풀고, 정답/오답 여부와 100점 만점 기준 최종 점수를 확인합니다.
2. **퀴즈 추가:** 새로운 F1 문제, 4개의 선택지, 정답 번호(1~4)를 직접 입력하여 등록하고 파일에 즉시 저장합니다.
3. **퀴즈 목록:** 현재 저장되어 있는 전체 퀴즈의 문제, 선택지, 정답 목록을 조회합니다.
4. **점수 확인:** 지금까지 플레이한 기록 중 최고 점수(best_score)를 확인합니다.
5. **종료 및 예외 처리:** 잘못된 숫자/문자/빈칸 입력 방어, Ctrl+C 강제 종료 시 안전 저장, 데이터 파일 손상 시 기본 데이터 자동 복구 기능을 지원합니다.

## 5. 파일 구조
- `.gitignore` : Git 버전 관리 제외 파일 목록
- `README.md` : 프로젝트 소개 및 실행 안내 문서
- `main.py` : Quiz 및 QuizGame 클래스, 메인 실행 코드
- `state.json` : 퀴즈 목록 및 최고 점수 저장 데이터 파일 (UTF-8)

## 6. 데이터 파일 설명 (state.json)
- **파일 경로:** 프로젝트 루트 디렉토리의 `./state.json`
- **역할:** 프로그램 종료 후 재실행해도 추가한 퀴즈 목록과 최고 점수가 유지되도록 UTF-8 인코딩의 JSON 형식으로 저장하고 불러옵니다. 파일이 없거나 손상된 경우 기본 F1 퀴즈 5개로 자동 초기화됩니다.
- **스키마 구성:**
  - `quizzes` (list): 각 퀴즈의 `question`(문자열), `choices`(문자열 4개 리스트), `answer`(1~4 정수)를 담은 객체 배열
  - `best_score` (int 또는 null): 최고 점수 기록
